# 영수증 메뉴별 정산

새 만남의 장소 입력 아래 `영수증으로 메뉴별 정산하기`를 엽니다. 영수증 사진 또는 OCR 없는 샘플 3종을 불러올 수 있습니다. Tesseract.js kor+eng를 브라우저에서 실행하며 사진을 외부 OCR 서버에 보내지 않습니다. worker/WASM과 한글·영문 모델은 앱과 함께 배포되고 출처·라이선스·SHA256이 `public/ocr`에 있습니다.

텍스트, 메뉴명, 수량, 행 금액을 수정하고 행을 추가·삭제할 수 있습니다. **행 금액은 수량을 포함한 총액**입니다. 숫자가 잘못 읽힌 행은 놓칠 수 있으므로 OCR 결과를 반드시 원본과 대조하세요. 표 합계와 영수증 총액이 다르면 경고하며 적용을 막습니다. `원본과 메뉴·수량·금액을 확인했어요` 체크가 필요합니다.

선택한 사람이 있는 메뉴는 그 사람끼리 균등 분할하고, 선택 없는 공용 항목은 전원이 균등 분할합니다. 기존 엔진의 participants 규칙을 그대로 사용합니다. 메뉴별 원 단위 나머지는 첫 결제자가 부담합니다. 메뉴 합산 후 할인 전 부담액을 가중치로 사용하여 할인 후 총액을 비례 배분하고 마지막 나머지도 첫 결제자에게 귀속합니다. 따라서 1원도 손실되지 않고 음수 부담액도 생기지 않습니다.

로컬 데모는 친구 역할을 한 기기에서 선택하여 시연합니다. 공유 정산은 생성 시 모든 선택·확정을 비우고 각 참여자가 자기 메뉴만 선택합니다. 모두 확정되면 송금 목록이 잠기고 송금 확인을 진행할 수 있습니다. 메뉴 행은 감성 영수증 카드와 PNG에도 표시됩니다.

3종 샘플은 떡볶이(22,000원), 카페(20,000원), 술자리(48,000원)입니다. 친구 넷의 1년 데모의 세 만남에도 메뉴와 감정 항목이 포함됩니다. OCR에서 장소명·주소를 자동 지오코딩하거나 은행·카드 연결로 지출을 자동 가져오지는 않습니다.
