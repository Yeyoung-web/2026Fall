# 공유 정산 흐름

1. 회원 또는 비회원이 친구와 지출을 입력하면 친구마다 역할이 다른 정산 링크가 생성됩니다. 링크는 30일 동안 유효합니다.
2. 링크를 열면 만남과 장소를 미리 봅니다. **참여하기**를 누르기 전에는 기록에 추가되지 않습니다. 링크를 먼저 참여한 사람의 세션에 역할이 귀속되므로 해당 친구에게만 보내 주세요.
3. 회원은 참여 시점에 회원 기록방에 만남과 장소가 추가됩니다. 같은 계정 집합의 만남은 같은 방에 모입니다. 비회원도 메뉴 선택과 정산 확인을 하며, 가입하면 기존 참여 기록을 보관합니다. 로그인 시 비회원 역할도 해당 계정으로 이전합니다.
4. 메뉴 영수증이 있으면 각자가 먹은 메뉴를 선택하고 확정합니다. 전원이 확정해야 송금 확인이 가능하고, 확정 뒤에는 메뉴를 수정할 수 없습니다.
5. 송금은 앱 밖에서 합니다. 보내는 사람만 **보냈어요**, 받는 사람만 **받았어요**를 누를 수 있습니다. 받는 사람 확인이 최종 송금 완료입니다. 모든 송금이 완료되면 카드가 현상됩니다.
6. 회원만 사진·감정·댓글과 지속되는 기록방을 사용할 수 있습니다. 사진은 참여한 회원만 조회할 수 있습니다. 알림은 앱 내부 알림이며 이메일·문자 전송은 없습니다.

`server/transfer-provider.mjs`의 MockTransferProvider는 **보냈어요** 단계의 어댑터입니다. 실제 돈을 보관하거나 이체하지 않습니다. 나중에 공식 사업자 어댑터로 교체할 때 같은 idempotencyKey를 사용하고 중복 요청을 처리해야 합니다. 받은 사람의 현재 수동 확인은 은행 검증이 아닙니다. 금융 API와 추측한 딥링크는 구현하지 않았습니다.

HTTP API는 Node.js 24 내장 SQLite를 사용합니다. 세션/초대 토큰은 무작위 32바이트·DB에는 해시, 비밀번호는 salted scrypt, 쿠키는 HttpOnly·SameSite=Lax입니다. 쓰기 Origin 검사, 역할별 접근 검사와 요청 제한을 포함합니다. 개인 계좌는 본인과 해당 계좌로 송금할 사람에게만 보여 줍니다. 이메일 인증·비밀번호 복구·계정 삭제 등의 운영 계정 기능은 아직 없습니다.
