# BITE 로고 02

한입 베어 문 B를 중심으로 만든 커스텀 대문자 워드마크입니다. 색상은 산호색 #F65336, 차콜 #252622, 웜화이트 #F7F5EF입니다.

- bite-logo.svg / png: 기본 로고. PNG는 투명 배경입니다.
- bite-logo-black.svg / png: 단색 로고.
- bite-logo-white.svg / png: 어두운 배경용 흰색 로고.
- bite-mark.svg / png: B 심볼만.
- bite-app-icon.svg / png: 산호색 배경 앱 아이콘. PNG 1024×1024. 원본은 사각형이며 플랫폼에서 모서리를 처리할 수 있습니다.
- BITE-logo-preview.png: 사용 예시.

SVG는 글자를 외부 폰트에 의존하지 않는 패스로 제작했습니다. 투명 PNG와 SVG의 비율을 유지하여 사용하세요. 생성형 이미지가 아닌 직접 작성한 벡터입니다.
